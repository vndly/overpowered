PxPlus_IBM_VGA8.woff2 is the file "woff - Web (webfonts)/WebPlus_IBM_VGA_8x16.woff"
from that archive, repackaged from WOFF to WOFF2 with fontTools. The repackaging
changes the container only: glyph outlines, character map, glyph order and metrics
are identical to the published file. The typeface itself is unmodified.

Why this build: "WebPlus" is the web release of the PxPlus variant, the IBM VGA 8x16
face extended past code page 437. Its em box is exactly one 8x16 character cell, so at
font-size: 16px one character measures exactly 8 x 16 CSS pixels, which is what the
character grid in docs/plan.md is built on.
